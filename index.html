A thousand hands on your desktop.

Senju is a computer-use agent swarm for the Mac. Each agent has its own cursor, working in your team’s real apps while you keep working in yours.

Download for Mac

A swarm you can interrupt.

Most computer-use agents run out of sight and hand back a result. Senju's agents work in front of you, in your own browser and Mac apps, and they stay answerable the whole time.

  • Write to the lead or to any worker while it works. It replans.
  • Pause an agent, take over its window, hand it back.
  • Sign-ins and anything sent in your name wait for your click.

Repurposing a text-only coding agent model for computer use.

Senju runs on Ripple, a model trained to write code in a terminal. It reads text and writes shell commands, and it cannot take an image. Computer-use agents normally work from screenshots, so Senju does not ask Ripple to be one. Each worker gets a terminal with one program in it, senju, and the screen arrives as text.

One tool, used like a terminal

A worker has a single tool, sh. Each line is one senju command. Lines run in order and stop at the first error, and Ripple can chain them with && as it would in a real shell. Every reply starts with ok or error, and an error says what to run next.

The accessibility tree is the screen

senju look reads the browser's accessibility tree, the structure a screen reader uses, and prints it as a short listing: the controls first, each with an id such as e12, then the page's text. An id stays with its element for as long as the element is on the page. A look is capped at 6,000 characters. After every action the shell prints only what changed, so the model sees the effect without looking again.

OCR for what the tree leaves out

The tree holds only what a page declares. Words painted into a canvas, a chart or an image are missing from it. OCR is the second reader for those surfaces: it lifts the words out of the pixels and adds them to the same listing, so Ripple still never receives an image. Between the two readers, a model that has never seen a screenshot can read anything a person can.

The commands

See

senju look [--full]
What is on screen now: the page, its controls with ids, then its text.

Act

senju click <id or "label">
Click a control by id, or by the label a person would read.
senju type <id> "text" [--submit]
Replace the text in a field. --submit presses Enter after.
senju select <id> "option"
Pick an option in a dropdown.
senju key <combo>
Press keys: enter, tab, cmd+a.

Go

senju search "words"
Search the web. A guessed address that does not exist turns into a search too.
senju open <url or app>
Go to a page whose exact address is known.
senju back
Go back one page.

Work as a swarm

senju board post "note"
Share a finding with the other workers.
senju board read
Read what the others have posted.
senju wait <worker>
Block until that worker reports.
senju wait <duration>
Pause for up to 30 seconds while a page settles.

Talk to the person

senju ask "question"
Ask the person and wait for the answer.
senju done "report"
Finish the subtask with a short report.
senju help
List the commands.

Anything that sends, pays or deletes stops for a person's approval before it runs. The same command with the same result three times in a row is refused, so a worker cannot loop.

Every job leaves a skill behind.

When a job ends, the lead writes a short retrospective and saves what it learned as a skill: a plain Markdown file you can read, edit or delete. The next job that resembles it starts from that file. In a team, skills are shared and every revision is kept.

Autoresearch teaches one task at a time.

Ripple's weights never change. What improves is the skill it reads. In the repo, the same loop runs on purpose and unattended: a researcher agent runs a task, reads where Ripple went wrong, and edits that task's skill.

  • A generation is six runs of one task, each on a fresh variant with different names, amounts and row order.
  • Milestones give partial credit, so a run that gets halfway still tells the researcher something.
  • The researcher opens the failing transcripts, finds the first wrong move, and changes one thing in the skill.
  • The change is kept if the score rises. Otherwise the skill is restored from the last version that won.
  • A fixed set of variants the researcher never reads decides when a skill is ready: five of six, twice in a row.
  • A ready skill is exported into the app as the same Markdown file a finished job would have left.

Install

  1. Download the app and drag it to Applications. Apple silicon or Intel.
  2. Open it the first time from System Settings. This build is not yet notarized by Apple, so macOS stops it once. Go to Privacy & Security and choose Open Anyway.
  3. Add your Anthropic API key. The app asks the first time you run a job. Agents run on your own key, which stays on your Mac.
  4. Press Command Shift Space and say what you want done. The same keys hide the bar and bring it back.
